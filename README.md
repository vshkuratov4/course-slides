## How each deck is built

1. **Lecture notes:** every topic explained plainly with a diagram, including where each formula comes from and when to use it.
2. **Try it / Solution pairs:** a worked example for every topic, solved step by step with the reason for each step.
3. **Final check:** practice problems, then a full step-by-step answer sheet.

Every numerical answer is checked with an independent circuit solver.
