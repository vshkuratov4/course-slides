# Study slides by Vladislav Shkuratov

Free, in-depth study slides for engineering courses: theory, shortcuts,
common exam traps, worked examples, and practice problems with full solutions.

**Website:** https://vshkuratov4.github.io

## Courses

| Course | Decks |
|---|---|
| ELEC 275, Principles of Electrical Engineering | Week 1: Circuit Concepts |

More courses (SOEN, COMP, ENGR) will be added over time.

## How each deck is built

1. **Lecture notes:** every topic explained plainly, with a diagram.
2. **Try it / Solution pairs:** a worked example for every topic.
3. **Final check:** practice problems, then a full answer sheet.

Every numerical answer is checked with an independent circuit solver.
